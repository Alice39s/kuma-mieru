# Kuma Mieru :traffic_light:

Kuma Mieru 是一款基于 Next.js 16、TypeScript 和 Recharts 构建的第三方 Uptime Kuma 监控仪表盘。部署、配置和开发说明都在[文档站](https://alice39s.github.io/kuma-mieru/zh/)。
