# Kuma Mieru :traffic_light:

Kuma Mieru is a third-party Uptime Kuma monitoring dashboard built on Next.js 16, TypeScript and Recharts. Deployment, configuration and development are covered on the [documentation site](https://alice39s.github.io/kuma-mieru/en/).
